# Translations

## How it works

`public/js/i18n.js` implements gettext-style lookup:

```js
import { t } from './i18n.js';
t('Construction complete: {n}', { n: name });   // English source string IS the key
```

- The active language comes from `localStorage['snowline.lang']`, falling back to the browser language and then English. You can switch it on the title screen or in the in-game menu (switching reloads the page).
- `IT` in `public/js/i18n-it.js` maps English → Italian (about 760 entries, grouped by source file). A missing key falls back to the English text.
- `{placeholders}` are substituted after lookup, so translations may reorder them but must keep the same names.

## Rules

1. Wrap every user-visible string in `t()`. Table data (catalog names and descriptions, campaigns, awards, advisor quotes, weather and surface names, complaint names) is stored in English and translated where it is displayed (`t(L.name)`).
2. **Changing an English string changes its key.** Update the matching `IT` entry in the same change.
3. **Don't build sentences by concatenation.** Use one key with placeholders (`t('{d} piste', { d: … })`), because Italian word order differs. Runtime-composed titles are assembled from translated parts (`compTitle()` in events.js builds "Coppa del Mondo di sci alpino – Discesa libera 2026/27").
4. Same English word, different meaning: add a distinct key. For example, the building button uses `'Open building'` → "Apri" because `'Open'` (the status) is "Aperto".
5. JS string escaping: use double quotes for Italian values with apostrophes (`"l'impianto"`).
6. Not translated on purpose: world.js build-validation errors, server error messages, OSM names, resort names, news posted by other players.

## Checking coverage

Run this from the repo root. It lists `t('…')` literals that have no Italian entry:

```bash
node --input-type=module -e "
import fs from 'fs'; import path from 'path';
const { IT } = await import('./public/js/i18n-it.js');
const files = []; (function walk(d){ for (const f of fs.readdirSync(d)) { const p = path.join(d,f); if (fs.statSync(p).isDirectory()) walk(p); else if (p.endsWith('.js') && !p.includes('i18n')) files.push(p); } })('public/js');
const keys = new Set();
for (const f of files) { const s = fs.readFileSync(f,'utf8'); for (const m of s.matchAll(/\bt\(\s*(['\"])((?:\\\\.|(?!\1).)*)\1/g)) keys.add(m[2].replace(/\\\\'/g,\"'\")); }
const missing = [...keys].filter(k => !(k in IT));
console.log(keys.size, 'keys,', missing.length, 'missing'); missing.forEach(k => console.log(' -', k));"
```

Indirect keys (the catalog tables) aren't found by this regex; check them by switching the game to Italian and opening the build panels and windows.

## Adding a language

1. Create `public/js/i18n-xx.js` exporting `XX = { … }`.
2. Register it in `DICTS` in `i18n.js`.
3. Add a language chip on the title screen (`main.js`) and in the menu window (`windows.js`).
4. Add trailer texts to `TEXT` in `promo/director.js` if you want a localized trailer.
